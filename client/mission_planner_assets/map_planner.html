Endpoints (WGS84)
Start doubles as the mission's GPS anchor - Start Mission calls SetPositionOnMap(latitude, longitude) with this exact point, making it map-frame (0,0). The map's origin (Metadata tab) is computed relative to it, so moving Start reshapes where the map sits under the vehicle.
Heading the AUV is told it's facing at Start, compass degrees (0=North, 90=East, clockwise) - the map is always north-up, shown as the ▲N marker top-right and as a draggable arrow on the S marker below (grab its tip and drag to rotate). Sent to SetPositionOnMap's yaw at mission start.

Launch Delay
Wait time on the AUV itself before the mission does anything else, after Start Mission is clicked — time to disconnect the tether and let it submerge. Start Mission is sent immediately, still tethered; the wait happens on the vehicle, no further link needed.

Vehicle Maps — fast mission, no upload
Lists maps already saved on the vehicle (sent once via Upload to Vehicle, ideally over a fast Ethernet/manual connection). Start Fast Mission reuses one by name and only sends the small parameters above (start/goal/waypoints/delay/heading) - no pgm/yaml transfer - so a mission can be launched over a slow tether without waiting on a map upload.
Mission File — JSON only, reuses a saved map
Upload just a small mission JSON (start/goal/waypoints/heading/delay + the name of a map already saved - see Vehicle Maps above and Offline Maps in the Metadata tab) instead of a full map+mission upload. Works over any connection, including a Manual Connection test channel, so this is the flow to use for debugging the upload path without a real tether.

Offline Maps
Saves the current map (pgm + yaml + start/goal/waypoints) to the GCS laptop's own disk - reloading later needs no internet at all, unlike Fetch Map. Useful for areas with no connectivity: generate and save maps in advance while online.
